## 1. 行为状态机（FSM）

> 状态 = 当前正在做的动作表现。宠物对外表现 = FSM 状态 × 属性/情绪修饰层（见 07 §情绪清单）。

### 1.1 状态定义

| 状态 | 表现 | 由谁驱动 |
|---|---|---|
| `IDLE` | 站立发呆（轻微呼吸） | FSM 自决策 |
| `WALKING` | 朝某方向走（4 方向切片循环） | FSM 自决策 |
| `EATING` | 进食（短暂，2~3s） | 动作「喂食」/ 随机觅食 |
| `SLEEPING` | 睡觉（闭眼 Zzz） | 作息 |
| `SICK` | 病恹恹（抖动、灰暗 tint） | 结算后 health 触底 |
| `SAD` | 难过低头 | 心情长期低 |
| `EXCITED` | 开心跳跃 | 玩耍后短暂 |

> 扩展动作（清洁 Task.md M11 / 学习 M12，见 09 §5.3 / §5.2；「工作」不做）不新增独立状态：以「短动作动画 + 气泡」在现有状态上叠加表达，动作完成回到 IDLE/WALKING。如需独立表现再扩展（保持低改动成本）。

### 1.2 转移表（优先级自上而下）

| 当前 → 目标 | 条件 | 备注 |
|---|---|---|
| * → `SICK` | settle 判定 health 触底 | 最高优先级 |
| * → `SLEEPING` | 夜间 22:00~07:00 或宠物自主犯困 | |
| * → `SAD` | 心情<20 且持续 4h+（结算段） | 粘人 trait 高更易触发 |
| `SLEEPING`/`SAD`/`SICK` → 恢复 | 醒来/治愈/心情回升到 40+ | |
| `IDLE` → `WALKING` | 随机决策：IDLE 2~4s 后 | |
| `WALKING` → `IDLE` | 行走 3~5s 或触墙换向 N 次后 | |
| `IDLE`/`WALKING` → `EATING` | 「喂食」动作/随机觅食触发 | 进食完回 IDLE/WALKING |
| `IDLE`/`WALKING` → `EXCITED` | 「玩耍」动作成功 | 2~3s 后回落 |

转移实现：domain 内 `BehaviorFSM.step(now, snapshot): FSMResult`，纯函数，返回下一状态 + 帧/dir/pos/气泡，不直接操作 UI。决策倾向的 trait 加权见 §4。

## 2. 行走模式（圆屏防穿模 + 4×4 切片）

### 2.1 坐标模型
- 归一化坐标 `(x,y) ∈ [-1,1]²`，原点屏心。
- 活动边界为圆：`x² + y² <= R²`（R≈0.82，留环形进度区）。

### 2.2 防穿模行走算法

```
行走决策循环（FSM tick，tick≈250ms，4FPS）：
  1. 边界外或前方 < margin → 随机转向（4 方向中选不撞墙）
  2. v = base(0.03/tick) × speedFactor(traits.activity)   // trait 驱动速度
  3. newPos = pos + dir × v
  4. if (x²+y² > R²) → clamp 圆内，转向
  5. 当前 dir 切片帧循环（frame 0→3）
```

**随机决策**：`WALKING` 持续时长 = 3~5s × trait 修正（activity 高→短、低→长），后随机 `IDLE` 2~4s，再换向。方向用 `0..3`（映射见下）。

### 2.3 4×4 素材切片读取

每张 `assets/sprite/<NAME>.png` = **256×256，4×4 网格**（4 朝向 × 4 帧，单帧 64×64）。

- 常见布局假设：**每行=朝向（0下/1左/2右/3上），每列=帧**。**待实测校验**（编码前用 `BULBASAUR.png` 实测），朝向→行号做成可配置常量，便于个别表修正。

```
val framePixel = 64
fun frameOf(dir: Int, frame: Int) = Rect(
  left = dir*framePixel, top = frame*framePixel,
  right = left+framePixel, bottom = top+framePixel)   // 若行列互换则调整
```

行走帧序 `0,1,2,3,…` @4FPS（每帧 250ms）。渲染见 [07](./07-渲染与动画设计.md)。

## 3. 昼夜作息

| 时段 | 行为倾向 | 数值影响 |
|---|---|---|
| 07:00~22:00 | IDLE/WALKING、可互动 | 正常消耗 |
| 22:00~07:00 | 倾向入睡 | 消耗大降 |
| 深夜仍醒 | 打哈欠 → SLEEPING | 互动收益=0 |

实现：FSM tick 读取本地「作息时钟」（本地时区），SLEEPING 属性衰减极低并回血。

## 4. 性格特质（trait）模型 —— 数值驱动，非固定模板

> 用户决策关键升级：性格**不是**「固定标签模板」，而是一组**数值特质**，宠物每个行为决策倾向都由这些值实时加权；同时开档随机给予，实现 文静/温柔/调皮/睿智/活泼 等无限组合的「个性化」。

### 4.1 两类因子

| 因子 | 来源 | 是否可变 |
|---|---|---|
| **不可变特质** | 开档骰定（seed），一生不变 | 否 |
| **可变属性**（智力/清洁度等，见 01 §1/§4） | 由操作/时间改变 | 是 |

两者的作用统一进「决策倾向函数」：`tendency(decisionKey) = f(traits, attributes, context)`。

### 4.2 不可变特质集合（6 维，每维 0~1）

| trait | 含义 | 主要影响（→ 决策倾向） |
|---|---|---|
| `activity` | 好动 ↔ 慵懒 | 行走速度、WALKING/IDLE 时长比、玩耍热情 |
| `affinity` | 粘人 ↔ 独立 | 迎接反馈强度、SAD 触发易度、被抚摸/陪伴需求 |
| `appetite` | 贪吃 ↔ 挑食 | 饱腹衰减速率、乞食频率、食物口味权重（口味偏好 flavor） |
| `curiosity` | 好奇 ↔ 淡定 | 随机事件可用池与触发权重、探索频率 |
| `temper` | 温和 ↔ 急躁 | 心情波动幅值、情绪表达强度（蹦跳更欢/生气更明显） |
| `learner` | 聪慧 ↔ 憨直 | 智力增长速度、新互动解锁所需次数 |

开档生成：`seed` 随机 → 六维均匀取样；同时派生 `flavor`（口味偏好：树果/清淡/甜口/新奇…）供食物契合（[01 §7](./01-状态与数值系统设计.md)）。

### 4.3 由数值派生「性格描述词」（仅文案，非逻辑）

根据 trait 组合给出主副描述词，用于建档页与气泡（如：活泼+粘人=「调皮粘人的小家伙」）。示例映射：

| trait 组合特征 | 描述词 |
|---|---|
| activity 高 + curiosity 高 | 调皮 / 活泼 |
| activity 低 + temper 高 | 文静 / 温柔 |
| affinity 高 + activity 低 | 粘人 / 温顺 |
| learner 高 + curiosity 高 | 睿智 / 机灵 |
| appetite 高 | 贪吃 / 小吃货 |

> 描述词仅为玩家感知包装；**一切决策与数值都以 trait 数值为准**，同一描述词下不同数值组合仍会有行为差异。

### 4.4 决策倾向函数（示例）

```
tendency(key) 由 traits/attributes/context 加权：
  moveSpeed       = base × (0.6 + 0.8×activity)
  walkDuration    = rand(3,5)s × (1.6 - activity)
  begFoodRate     = baseRate × (0.5 + appetite)          // 乞食频率
  sadThreshold    = moodThreshold(20) × (1.4 - affinity) // 粘人更容易想主人
  moodDecayFactor = (1.2 - temper×0.3)                   // 温和→心情更稳
  eventWeight(id) = id.baseWeight × curiosityFactor      // 见 03
  learnSpeed      = (0.5 + learner) × baseStudyGain      // 见 01 §4.1
```

### 4.5 trait 一致性保证

- trait 在 SP `personality.traits` 存一份（[01 §9](./01-状态与数值系统设计.md)），**开档后不可变**。
- 可变属性（智力/清洁度）参与部分倾向计算，但变化**只产生增益/轻度联动**，不惩罚（无压力）。

## 5. 行为层对外接口草案（domain）

```
interface BehaviorFSM {
  fun step(now: Long, snapshot: PetSnapshot, tickMs: Long = 250): FSMResult
  fun onFeed(now, s, food: FoodType): ActionResult   // 食物类型驱动效果
  fun onPlay(now, s, toy: ToyType?): ActionResult    // 玩具变体预留
  fun onPet(now, s): ActionResult
  fun onHeal(now, s): ActionResult
  // 预留：onClean / onStudy → M11 / M12（Task.md，doc/09 §5.2/§5.3）
}

data class FSMResult(
  val state: PetState, val dir: Int, val frame: Int,
  val position: NormalizedPoint,
  val bubble: BubbleText?,
  val emotionHint: Emotion?,        // 情绪修饰层提示（见 07）
  val deltaAttributes: AttributeDelta
)
```

渲染层每 tick 消费 `FSMResult` + `emotionHint`，见 [07](./07-渲染与动画设计.md)。
