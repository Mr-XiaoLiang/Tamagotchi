## 1. 主屏信息架构（一次一屏，层级最小化）

主屏（宠物游戏）是**唯一常驻场景**，核心要素在一个 Canvas/Compose 层内叠加（overlay 切换，避免主屏自身拆成多 Activity）；独立附加功能以后续 FeatureActivity 呈现（见 §10）：

```
┌────────────────────────────┐
│  ① 主环：三段环形进度条        │  饱腹(琥珀) | 心情(青绿) | 健康(玫红)
│    (图标-进度条-…回环)        │  弧角 = 槽位角-图标占位-间距
│        ③ 状态图标区(顶内)     │  异常才出现的提示小图标（脏/病/困…）
│      ▼ 顶部下拉提示          │  下拉=状态面板（学系统下拉，同点 ③）
│ ② ──── 宠物层（最底·全屏）─── │  切片动画走满整屏；模型≈0.30 屏径
│      (宠物+气泡)             │  宠物恒不出屏；与上叠环/箭头重叠属预期
│                            │
│     ▲ 底部上滑提示           │  上缘下拉/下缘上滑/右缘左滑 三方向
│          ◀ 右缘左滑提示      │  （规避“从左往右”：系统返回）
└────────────────────────────┘
```

- **基底 = 纯黑 `#000000`**（§4.1 界面 Token）：圆屏与设备表盘黑边视觉一体（隐藏黑边、无割裂感）；**整体背景基调 = 深色**，全 App 风格一致。
- **页面主题背景（允许，见 §4.2）**：功能页**允许以同心圆渐变作主题背景**以区分功能页面——色相可作页面标识，但必须**低亮度、低饱和的深色调**；**不以高亮/高饱和为主色调**（大面积亮/高饱和主色在设备黑边下会明显割裂）。
- **防屏缘割裂红线**：**高对比/鲜艳色不得触达或被屏幕边缘截断**（与屏幕边框强烈对比 = 割裂）；鲜艳色只落在中央内容（主环/宠物/图标/气泡，不与屏缘相交）——这也是游戏状态色可保持相对鲜艳的边界条件。
- 主环外缘半径 `R_ring ≈ 0.96`（屏半径=1；距屏缘 4dp 呼吸位，贴边充当刻度环），带宽 6dp；**布局 = 全屏叠层（用户拍板修订，doc/00 T-21）**：宠物渲染在**最底层、画布 = 全屏**，主环 / 状态图标 / 三向把手为**上层 overlay**，允许宠物与环带 / 箭头**重叠**（宠物从下方经过被其遮挡属预期叠层）。**宠物活动范围 = 整个屏幕**：归一化 pos 的 R=1 = 宠物中心最大可达圆，渲染映射再扣除模型半径与呼吸余量，**模型恒不出屏**（像素偏移 = pos × (屏半径 − 模型半径 − 呼吸余量)）。**模型精灵 ≈ `0.30` 屏直径**，模型尺寸与活动范围是两个量——全屏只是可跑范围，不放大模型。
- **方向约束（重要）**：本设备「从左往右滑动」= 系统级返回/关闭页面操作，因此**不设计任何从左缘发起的手势，布局也不占用左缘**。自定义手势三个：**上缘下拉**（状态面板，学系统下拉）、**下缘上滑**（操作面板）、**右缘左滑**（功能清单）。
- 上/下/右缘把手 = **白色半透明小箭头**（Material Symbols single_arrow，视觉 ≥16dp，**无底色/描边/文字标签**；透明点击热区 ≥40dp），**贴主环内沿悬浮、属上层 overlay**（定位容器透明，不挡宠物 hit；宠物可从箭头下方重叠经过）；可点按直达（增强可达性）；提示随所属层就绪逐一揭示，非开机一次性全亮（时序见 08 §1）。**延迟自动隐藏**：每箭头从**自身显现时刻**起计 **10s** 后自动淡出（三把手分属不同业务层、启动就绪时点不同，故各自独立计时；淡出后不再复显，入口仍由边缘滑动手势 / 面板内收起钮承担）——避免常驻箭头的持续观感问题。

## 2. 主环：三段环形进度条

- **圆环排列 = 图标→进度条→图标→进度条→图标→进度条→（回环到首个图标）**：从 12 点起顺时针依次 饱腹(碗) → 心情(🎈) → 健康(十字)，配色固定；图标均分圆周充当**段界**。
- **弧段角度不固定为 120°**：每段槽位角 = 360°/3 = 120°，但弧段只占**减去两侧图标角向占位、间距与圆头端帽留空之后的剩余角度**（实际 < 120°），使各段互不粘连、图标两侧留白。
- 数值映射：前景弧长 = `attr/100` × 弧段可用角；底轨同角低透明度常显（三段三轨骨架）。
- 低值预警：`<30` 该段图标呼吸闪烁（1s），对应 01 §3「告急 RED」预示原则。
- 实现：Compose `Canvas.drawArc` × 3 + 图标 layer（`ui/RingProgressBar.kt`），不引入第三方环形库。

## 3. 状态图标区与状态面板（无素材的状态表达）

> 无表情/病容素材时，用「屏内状态图标 + 状态面板」做**信息双通道**（图标提示 + 面板详情），不依赖贴图本身。

### 3.1 状态图标区（主屏顶部内侧）

- 位于宠物上方、主环内沿的「提示带」，**只在异常时出现** 1~3 个小型状态图标（如 饿=碗、闷=云、脏=水滴、病=十字、困=月牙、初级=书）。
- 点图标 = 顶部下拉展开「状态面板」（等效上缘下拉 / 下面板「状态」，见 §3.2）——对齐系统下拉面板的潜意识。
- 图标配色与对应属性一致（§4），异常才亮起——避免常驻噪音。

### 3.2 状态面板（顶部下拉面板）

打开方式（**同一面板、三个等价入口**）：
1. **上缘下拉**——对齐系统下拉（Quick Panel）的习惯；
2. 点屏顶状态图标区（§3.1）；
3. 底部操作面板的「状态」项 → **收起下面板、顶部展开状态面板**（下面板内不翻页，见 §6）。

面板从顶部滑入（**放下层收上层**，与系统行为一致）；收起：点击面板上**▲ 反方向箭头收回钮** / 面板内上滑 / 点外部 / 系统返回键/手势。
呈现：每条 = 属性图标 + 名称 + 迷你进度条 + 数值（%），按类别分组：

```
状态
  饱腹度   ▓▓▓▓▓▓▓░░░  62%   饱腹(琥珀)
  心情     ▓▓▓▓▓▓░░░░  50%   心情(青绿)
  健康     ▓▓▓▓▓▓▓▓░░  80%   健康(玫红)
  智力     ▓▓░░░░░░░░  15%   智力(蓝紫)     ← 隐藏属性
  清洁     ▓▓▓▓░░░░░░  45%   清洁(浅蓝)     ← 隐藏属性
当前状态：WALKING / 心情：还好 / 最近：2 小时前你喂过我
```

- 属性注册表驱动渲染（01 §1.3），未来新增属性自动出现在列表。
- 面板只读；属性行 = **空心胶囊（OutlinePill）信息行**（不可点击，见 §8.3）；圆屏内用纵向紧凑 **RoundList**（可滚动/旋转表冠、边缘渐隐，见 §8.2），禁止手机式宽表。

## 4. 配色表（属性 / 状态统一 Token，莫奈低饱和基调）

> **莫奈低饱和总则（用户决策）**：所有「鲜艳色/语义色」——含主环弧段、状态图标、进度条、气泡小圆点、**胶囊类别覆写色**——统一倾向**莫奈印象派式的低饱和柔和色**：压低饱和、保留色相辨识（颜色仍是信息），在纯黑大底上**不刺眼、更一体**。下表为低饱和参考初值，色值以 `ColorToken` 集中管理，编码期可微调。

| 属性 | 色（低饱和） | 状态 | 色（低饱和） |
|---|---|---|---|
| 饱腹 satiation | 琥珀 #D9AF85 | IDLE | 灰 #B0BEC5（原灰蓝已低饱和，不变） |
| 心情 mood | 青绿 #84BCAE | WALKING | 青 #79B3A6 |
| 健康 health | 玫红 #CF9AA2 | EATING | 橙 #DCA46E |
| 智力 intelligence | 蓝紫 #9E94C9 | SLEEPING | 蓝 #8792BE |
| 清洁 hygiene | 浅蓝 #93BFCF | SICK | 紫红 #C6899E |
| | | SAD | 靛 #7E8FB4 |
| | | EXCITED | 亮黄 #E6CD8C（情绪峰值可略亮，仍压饱和） |

颜色用于：主环弧段、状态图标、状态面板进度条、气泡小圆点（当前 FSM 状态色）。色值以 Compose `ColorToken` 常量集中管理（theme/Color.kt）。

### 4.1 界面 Token（基底 / 页面主题背景 / 统一主题色 / 胶囊状态）

| Token | 初值 | 用途 |
|---|---|---|
| `bg` | 纯黑 `#000000` | **全局基底色**：圆屏与黑边一体（隐藏黑边）；一切页面由 bg 出发，整体基调深色 |
| `PageGlow` | 页面自定（低饱和深色调） | **页面主题背景 RadialGradient 中心色**（§4.2）：低亮度低饱和、色相标识功能页；禁止高亮/高饱和主色 |
| `Accent` | 近白 `#F2F3F5` | **统一默认主题色**：实心胶囊填充/描边/主文字；集中一处管理（可整体换品牌色），禁止各功能自造主题色 |
| `OnAccent` | 黑 `#101418` | 实心胶囊内文字/图标（Accent 上的反色） |
| `Text2` | 灰 `#B0BEC5` | 次要文字 / 空心胶囊内容（复用 IDLE 灰） |
| `Pill.Filled` | Accent 容器 | **实心胶囊 = 可点击**（默认同主题色；类别项允许覆写背景，见 §8.3） |
| `Pill.Outline` | 透明 + 1dp 描边 | **空心胶囊 = 不可点击**：只读行 / 冷却·锁定信息位 / 暂不可用项（见 §8.3） |

- `PageGlow` 只作用于**页面主题背景层**（RadialGradient 中心色，§4.2），渐变**最外圈恒为 `bg` 纯黑 `#000000`**（无独立收尾 Token，终点即 `bg`）；内容层（胶囊/文字/图标/主环）浮于其上，仍按 Accent / 低饱和语义色呈现，不随页面色相漂移。
- 上表与属性/FSM 语义色（§4）并行：图标/进度条仍用语义色（莫奈低饱和，颜色即信息），**胶囊主题统一走 Accent**——保证整体不彩虹、UI 色不稀释语义色。

### 4.2 页面主题背景：同心圆渐变（允许，但深色基调）

- **动机**：功能页（功能清单 / 设置 / 插件页 / 游戏内子页…）**允许以同心圆径向渐变作主题背景**，用**色相区分功能页面**——同功能族同色相、异族异色相，让不同功能页在纯黑基底上一眼可辨，又不失整体深色一致。
- **实现 = RadialGradient**：页面主题背景统一用**径向渐变 RadialGradient**（Compose `Brush.radialGradient`）渲染同心圆渐变，圆心通常偏上/正中——中心 = `PageGlow`（低饱和深色调主色，可带**极淡辉光**），随半径向屏缘扩散，**最外圈 = 纯黑 `#000000`（硬性收敛，不允许深灰/半透明/带色收尾）**；主屏（宠物常驻）以纯黑为主、中央极淡辉光即可，不铺整屏渐层，保宠物/主环对比。
- **硬约束**：
  1. **主色限深色基调**：`PageGlow` 必须低亮度、低饱和（风格一致）；**不以高亮度、高饱和为主色调**——大面积高亮/高饱和主色在设备黑边下会明显割裂；
  2. **最外圈必须全黑**：RadialGradient 终点（= 圆屏最外缘）恒为 `bg` 纯黑 `#000000`，禁止彩色/深灰收尾——屏缘与表盘黑边**零色差**，黑边完全隐藏；
  3. **内容层屏缘禁高对比**：任何高对比内容（亮色块、高饱和描边、亮文字带）**不得触达或被屏幕边缘截断**——背景层因最外圈全黑已自洽，此条针对浮于渐变之上的内容 UI（与屏幕边框强对比仍割裂）；
  4. **鲜艳色只进中央**：语义色（状态弧/图标/气泡/进度条）属相对鲜艳色，**只放不与屏缘相交的中央内容**（安全区内）——不与边框对比故不割裂；游戏状态色即属此列（配合 §4 莫奈低饱和更克制）。
- 例外：壳层首帧（黑屏 → 居中 Logo，08 §1）与系统级过渡不套页面主题背景，保持纯黑。

## 5. 手势系统（一次一种，方向受约束）

| 手势 | 区域 | 触发 | 备注 |
|---|---|---|---|
| 点击宠物 | 中央 | 抚摸互动（亲昵气泡，遵循冷却） | 陪伴向轻互动 |
| **下拉** | 上缘 | 顶部下拉展开**状态面板**（学系统下拉，与点屏顶状态图标同效） | 从上往下 |
| **上滑** | 下缘 1/4 | 拉起**游戏操作面板**（主链：投喂/玩耍/抚摸/治疗 + 首项「状态」…见 09 §3） | 从下往上 |
| **左滑（右缘发起）** | 右缘 | 展开**原生功能清单**（05 插件页，含通讯类） | 从右往左；快捷不依赖宠物 |
| 轻点提示箭头 | 上/下/右缘 | 等同对应手势（辅助/无障碍） | |

**箭头样式（统一）**：所有方向箭头使用 **Material Symbols Outlined「single_arrow」字形**（ImageVector 内嵌路径绘制，24dp，实心单箭头；方向 = 字形旋转 0°/90°/180°/270°），顶面板收回=▲、下面板收回=▼、右面板收回=▶；**不用文本字符**（↑↓←×）也**不用手工画线箭头**。

**打开 = 跟手拖出（无「阈值后弹出」）**：抽屉开启**不设固定位移阈值再弹出**——手指从三向带（上缘约 40%、下缘约 40%、右缘约 55% 内）按对应方向推动时，**整块面板沿轴向整体平移、1:1 跟随手指滑入屏内**（拖多远露多宽，屏幕上出现的是「一整块随手指移动的抽屉」，不是面板钉在原位、用 clip 裁可见窗口的“拉开布帘”效果），未覆盖区仍见主屏，拖动即有反馈；**松手过半自动滑满、不足一半弹回收起**。判定需同轴主导（防横竖误触）+ 起点带匹配，且监听不吞 down（长按共存见 §11 #11）；点提示箭头 = 同效点击展开（带滑入动画）。
**规避方向**：不使用任何「从左往右」的手势/布局（=系统返回）。
**收起规则（含可见把手）**：手表无全局返回手势，三个面板各在面板上提供**反方向 single_arrow 箭头收回钮**（点击 = 面板反方向滑回，抽屉隐喻；顶=上推、下=下拉、右=右推）。**收起钮所在固定条带必须置于面板对侧、滚动列表之外的独立区域**（列表滑动不影响它）：顶面板（状态）= 条带固定在**最底部**；底面板（操作）= 条带固定在**最顶部**；右面板（功能）= 竖条带固定在**最左缘**。条带内只放一枚箭头（无文字/底/框），标题仍作为滚动流首元素留在列表里（§8.1）。**条带本身瘦身**：外层仅做透明占位把箭头钉在对侧（横：高 ≈36dp；竖：宽 ≈36dp，**三面板截面同尺寸**），**可点热区只围绕箭头那一小块**（横 ≈48×36 / 竖 ≈36×48dp，热区 ≥30dp 即可），整行/整列空白**不参与点击**——视觉上只有一枚箭头，不是一条按钮带（竖条曾占面板近 1/3 宽，见 §11 #10）。另有：点外部区域、系统返回键/手势兜底。
**面板背景**：三个 overlay 面板背景**不透明纯黑**（`bg`），不透出主屏内容，保证内容可读。
**面板几何 = 全宽抽屉**：三个面板都是**自对应屏缘整体平移滑入的整块不透明面板**（顶=自上而下滑入、底=自下而上、右=自右向左），且**宽度一律占满屏宽**——右面板**不得**收窄成 ≈0.86 宽再贴右缘（否则其左侧会留出一条「面板同色空区」，视觉上与收起条连成一大片宽带，见 §11 #12）；面板宽度一致，三处收起条截面也一致（36dp）。顶/底面板滑入停靠后高度为其内容所需，右面板占满整屏。
**下/上面板联动**：点击下面板「状态」= 收起下面板、顶部展开状态面板（收起下与展开上成对发生，见 §3.2 / §6）。

> 为什么点击宠物不是跳 App：用户决策——功能入口在独立清单；点击宠物保留为抚摸互动，避免误触跳第三方应用。

## 6. 游戏操作面板（下缘上滑）

## 8. 屏幕适配与圆屏组件化（RoundSafe）

- 圆形表盘（320~360px 级）为目标；布局用归一化半径（02），运行按 `min(w,h)` 换算。
- 方形屏兜底：中心圆绘制环形进度，四周留边距。
- **设备与最小尺寸（防失忆硬约束，真机 ~<2 英寸 / 逻辑宽约 230dp）**：所有排版按此小屏基准布置可读元素，**禁止为「塞更多内容」整体等比缩小文字/图标/箭头**——放不下就滚动、分页，不缩小。人因下限：文字 ≥11sp 且不透明（见下条）；**箭头/chevron/返回字形视觉 ≥16dp——列表行进项箭头与前后翻页箭头 ≥18dp、返回字形 ≥26sp 且中粗、不加圈**；触控热区 ≥30dp（主操作胶囊 ≥44dp）。层级一律用字重，禁缩小/降透明度（§11 #3/#7）。
- 字号：**所有文字（正文/辅助/说明）最小 11sp**，低于 11sp 在圆屏实测不可读（曾用 8~10sp，见 §11 #3）。**文字一律不透明**：强调用加粗（字重）表达，次要信息整档用次要色 `Text2`；**禁止缩小字号、也禁止降低文字透明度**来分层/弱化（低 alpha 看不清内容，见 §11 #3）。低 alpha 仅允许用于装饰底色/描边/轨迹，绝不用于字形。标题/强调 14sp 起，图标/箭头字形 16dp 起，遵循 Wear `MaterialTheme.typography` 与系统字体缩放。

### 8.1 圆屏呈现约束（为什么必须组件化）

- 圆形屏在**靠近边缘处有大幅裁切**：列表项 / 长文本 / 面板行若按手机式贴边布局，两端会被屏沿削掉。因此**所有「面板/清单/列表行」内容默认限定在「内切安全区」内**（距屏沿留足余量，运行按 `min(w,h)` 换算的固定比例；贴近屏沿的最外层装饰渐隐处理）。
- 列表一律**纵向紧凑、可滚动/旋转表冠**；禁止横向宽表 / 通栏行；行文本自动截断（ellipsis），两端不出安全区。
- **纵向列表交互结构（通用硬规则）**：**所有非特定布局（非固定/网格/表盘等专用排版）的纵向内容页**——面板清单页、整页列表（建档选宠列表等）、M6 起的食物/功能子页，以及**内容型详情/确认页（如建档预览「确认领养」页）**——一律为滚动流 **`[space、title、item…、space]`**：标题（详情页含返回键的头行）**不是**固定在屏缘/屏顶的独立头部，而是**滚动内容的首元素**；打开时首段保留约半屏空白（半屏减标题行半高），使标题初始落在屏中，随后条目/数值行/确认钮随滚动上行，可逐个停留屏中可读带；末段同值留白，使末项（确认钮等）也可滚至屏中可读区。首末留白统一用组件 `RoundEdgeSpace()`，禁止自行拍脑袋写留白。仅整表/表盘专用排版豁免（物种核对网格、主屏表盘等）。

### 8.2 圆屏组件库（RoundSafe，presentation/component）

所有面板/清单/气泡类界面统一用以下组件拼装；**新增功能面板/列表必须复用，不得自绘贴边布局**（T-17 / ADR-15）：

| 组件 | 职责 |
|---|---|
| `RoundSheet` | 上/下滑入面板：状态面板（顶部下拉）、操作面板（底部上滑）、功能清单（右缘滑入）；内置安全区内边距 + 边缘渐隐 |
| `RoundList` | 圆屏安全滚动列表（触摸/表冠），首尾项进入安全区即渐隐，不做手机式边缘出血滚动 |
| `RoundListItem`（PillItem） | 菜单/清单条目 = **统一胶囊**（§8.3）：icon 左置或纯文本；实心（可点）／空心（只读/锁定）自动分发；行高紧凑、裁切防护 |
| `RoundText` | 圆屏行文本：自动截断 + 两端约束在安全区内；居中/两端对齐均适用 |
| `EdgeFade` | 渐隐遮罩：统一处理近屏沿裁切，被裁的永远是最外层装饰而非内容 |

> 实现落在 Compose（Wear Material + Canvas），组件置于 `presentation/component`（00 §7 包结构）；**组件优先复用官方/系统组件**（Wear Compose Material3 / AndroidX），RoundSafe 为圆屏适配所需的自研补充，不自造可替代官方组件的轮子；屏幕兼容遵循官方 Wear UI 建议，安全区尺寸初值随 Phase 8 真机实测校准（00 T-20 / ADR-17）。

### 8.3 胶囊样式规范（Pill：统一主题色 + 实心/空心两级）

**所有菜单 / 清单 / 面板条目统一用「胶囊」形态**（功能清单、操作面板、状态面板、各类子页列表…），由胶囊条目组件拼装（T-18 / ADR-16）：

- **形态**：圆角胶囊，纵向一条一胶囊（RoundList 容器），高度与左右留白适配圆屏安全区，不贴边。
- **内容排布**：
  - 有 icon 的条目：**icon 居胶囊左侧** + 名称文字；
  - 无 icon 的条目：**直接纯文字**（居中，不空置 icon 位）；
  - 需引导时右侧可带小箭头 / 角标。
- **两级语义（硬规则，可点性一眼自明）**：
  - **实心胶囊 = 可点击**：填充 Accent 主题容器色（默认近白、内容 OnAccent 黑，按下加深），点击执行动作 / 进入子页；
  - **空心胶囊 = 不可点击**：透明底 + 1dp 描边、内容 Text2 灰——用于只读行（状态面板属性行）、冷却/锁定信息位、探测暂不可用项（如插件目标未安装）。
- **类别色覆写（允许局部）**：带类别语义色的条目可用其**类别容器色替换实心胶囊背景**——食物按 flavor 配色、属性类按 §4 属性色、宠物互动类按类型…；**无类别色条目一律保持默认 Accent**，避免全屏彩虹。
- 配色一律走 `ColorToken`（§4.1）；类别/语义覆写色遵循 §4 莫奈低饱和基调，任何组件不得写死新色值。

## 9. 无障碍与可用性

- 箭头 hint 可点按；TalkBack 语义标签：喂食/玩耍/抚摸/治疗/三段进度/状态图标。
- 胶囊点击区不小于 44dp；TalkBack 播报两级状态：可点（实心）/ 只读（空心）。
- 信息双通道：状态值经主环 + 图标 + 面板表达，不依赖单一动画变化。

## 10. 页面路由与 Activity 分层（轻量，无导航库）

主屏常驻 = **PetActivity**（: BaseActivity，见 08 §2），内部用 `sealed class Screen` 做 overlay 切换（轻量、秒开）：

```
PetActivity（主屏常驻；壳层由 BaseActivity 提供）
  ├─ StatusPanelOverlay（状态面板：顶部下拉；入口 = 下拉 / 屏顶图标 / 下面板「状态」）
  ├─ ControlPanelOverlay（上滑操作面板，含子页：选食物）
  ├─ BubbleLayer（气泡浮层）
  └─ PluginListOverlay（右缘左滑，快捷功能清单——不依赖宠物状态，壳层内先行可用）
```

**功能隔离（用户决策）**：后续独立功能（便条 / 成就 / 设置…）以**独立 `FeatureActivity : BaseActivity`** 追加、manifest 注册、`startActivity` 触发——首页只加载宠物陪伴所需代码，保持纯净；主屏内 overlay 不经导航库（00 ADR-12 / T-16 / 09 §5）。

## 11. 已知问题与防复发清单（Known Issues / Pitfalls）

> 汇总代码评审与实机曾复现的布局/文字问题。**改动 UI/排版前先读本清单；同类问题禁止再次出现**。每条 = 现象 → 根因 → 防复发规则。

| # | 曾发生现象 | 核心根因 | 防复发规则 |
|---|---|---|---|
| 1 | 内容/标题/返回键被圆屏上下沿裁切、底部数值与按钮看不到 | 手机式布局：内容从屏顶硬排、标题固定钉顶/钉侧，只考虑水平安全边距，忽略圆屏顶底窄带 | 内容型页面一律**滚动流 `[space、title、item…、space]`**，首/末用 `RoundEdgeSpace()`；标题是滚动内容首元素（初始居中），禁固定屏缘头部（§8.1） |
| 2 | 建档「确认领养」这类内容页曾违反上述结构 | 把「非列表页」误判为「专用排版」而豁免 | 豁免**仅限整表/表盘专用排版**（物种核对网格、主屏表盘等）；内容型详情/确认页仍必须遵守 #1 |
| 3 | 文字过小/过淡看不清（8~10sp 或低 alpha：trait 标题、说明行、角标） | 为「塞内容 / 做弱化」把文字压到 8~10sp、叠低 alpha | **文字最小 11sp 且一律不透明**：层级用字重表达（强调加粗），次要文字整档用次要色 `Text2`；**禁止缩小字号或降低透明度**，低 alpha 只允许装饰底色/描边/轨迹，禁止用于字形 |
| 4 | trait 标题等文本被裁到「看不见」 | 给含文本的 `Row`/`Box` 锁死 `height`（如 10dp），小于字形行高，Compose 强制裁行 | **禁止给文本行设固定 height 压缩**；行高由文本自然撑开，容器只留足（必要时 `heightIn(min=…)`） |
| 5 | 返回箭头又小又难按 | 视觉上再套 24dp 小圆框包箭头，可写空间被圆环挤压、字形被迫缩小 | 返回/图标不加小圆框包字形；用大字形（≈26sp）+ ≥30dp 透明点击热区 |
| 6 | 整页主按钮（确认领养等）文字偏左不居中 | 胶囊仅 `weight(1f)` 左排文本、无对齐参数 | 胶囊组件提供 `textAlign` 参数；主行动/整页主按钮文字**居中**（列表只读行仍可左对齐） |
| 7 | 箭头/chevron/› 太小看不见（9~13dp / 13sp 字形） | 为省空间把箭头压成小号、用细小字形「›」，2 英寸屏上不可见 | **箭头/chevron 视觉 ≥16dp**（列表行进项/翻页 ≥18dp），返回字形 ≥26sp 中粗、不加圈；热区 ≥30dp；禁止为了“塞更多”缩小箭头（§8 设备约束） |
| 8 | 三面板收起钮被做进「滚动标题行」里：标题滚走钮跟着滚、位置不确定 | 把收起钮当成标题行的一部分（RoundHeader 内嵌按钮），违背「面板单独一块区域」 | 收起钮所在固定条带**在滚动列表之外、面板对侧**：顶面板→条带固定最底、底面板→固定最顶、右面板→固定左缘（§5 收起规则）；条带内仅一枚箭头，标题独立作滚动首元素 |
| 9 | 主屏三方向入口被做成「文字胶囊大按钮」，又丑又占中央；把手原先放中央空带挤占宠物 | 为可点性做整条大胶囊 + 文字；把手定位按屏半径随手放 | 主屏三向入口 = **白色半透明单箭头**（无底色/描边/文字；视觉 ≥16dp、点击热区 ≥30dp 透明），**贴主环内沿**悬浮，中央整圆让给宠物；**活动区 = 宠物可移动范围**，模型单独取 ~0.30 屏直径居中——**放大活动区 ≠ 放大模型**（§1/§5） |
| 10 | 面板收起条做成很宽/很高的整片空带（右面板竖条曾占宽近 1/3），像一条大工具栏；空白也全可点 | 为「独立区域」随手加大条带尺寸、整条 `clickable`，忘了条带只承载一枚箭头 | 收起条外层仅透明占位把箭头钉在对侧（横高 ≈36 / 竖宽 ≈36dp，三面板同截面），**可点热区只围绕箭头**（横 ≈48×36 / 竖 ≈36×48dp，≥30dp），整行/整列空白不可点；箭头视觉 ≥16dp（§5 收起规则） |

| 12 | 右面板（功能）宽度收窄为 ≈0.86 屏宽贴右缘：整体看「面板左侧余下一条同色空列」，与收起条连成一大片宽带，像返回区很宽；且实现一度把面板钉在原位用 clip 裁可见窗口，像“拉开布帘”而非抽屉 | 担心全宽盖住主屏而收窄；抽屉隐喻误用 clip 出窗实现 | 三面板一律**占满全屏宽**的整块不透明面板，收起条之外就是列表占满剩余宽（§5 面板几何）；抽屉开合 = **整块面板 `graphicsLayer` 平移滑入/出屏**（1:1 跟手），黑底随面板整体移动 |
