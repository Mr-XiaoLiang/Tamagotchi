# 电子宠物（拓麻歌子）手表 App —— 总需求与设计文档

> 本文是 **README 总文档**：面向所有读者，汇总产品定位、已确认决策、玩法总览、主屏信息架构、技术约束与开发阶段。
> 详细子系统设计见 [doc/](#文档索引) 目录；本文不重复各模块细节，只做总览与索引。

---

## 1. 项目定位

一款运行在 **Android 11（API 30）+ 圆形手表表盘**上的**单宠陪伴电子宠物**应用：

- **陪伴**：玩家从 1339 张宝可梦素材中任选一只，之后专注于照顾它——喂食、玩耍、抚摸、治疗；它按你的照顾状态实时做出反应，性格各异。
- **实用**：主屏右侧左滑可展开「原生功能清单」，模块化拉取常用 App / 系统设置 / 通讯呼叫 / 本地动作（微信、Wi-Fi、电话等）。
- **轻量**：极致秒开（< 200ms）、低内存（< 30MB）、低帧率省电（4~6 FPS）、后台 0 CPU。

性能红线（保留，见 §6 T-01~T-03）。

## 2. 设计决策摘要（已确认）

| 维度 | 决策 | 理由 |
|---|---|---|
| 形态 | 单宠档，开档可从 1339 张素材任选；换宠需重开档 | 专注陪伴 |
| 成长 | **形态固定、无进化、无阶段** | 纯陪伴定位 |
| 驱动 | **纯状态驱动**：表现由属性 + 行为状态即时决定，无长期记忆 | 简单轻量 |
| 离线 | **取消 AlarmManager/通知**，打开 App 时一次性结算（settle） | 0 后台 |
| 离线叙事 | 长离线结算生成**事件化回放剧**：「生理消耗事件」（骨架，承载自然衰减）+「突发扰动事件」（点缀，正负受控）按性格特质概率穿插、触发间隔带波动，打开时以「在你离开期间发生了…」呈现，作为**内存会话日志的开场段**（doc/03 §7 / doc/04 §3） | 每次数值消减都有过程可读，陪伴感增强 |
| 惩罚 | **无压力模式**：所有属性归零不死亡、不背叛/出走；离线最多生病（SICK），照顾即恢复 | 杜绝劝退体验 |
| 经济 | **不引入货币/工作报酬**；喂食免费但**食物分类型**，口味与性格特质匹配有加成 | 无压力 + 决策感，降复杂度 |
| 属性 | 三类属性：**主属性**（饱腹/心情/健康）+ **可变隐藏属性**（智力/清洁度，可更多）+ **不可变性格特质**（开档骰定 6 维 trait），性格=数值驱动的决策倾向而非模板 | 性格多样化（活泼/温柔/睿智…） |
| 存储 | 单宠快照存 **SharedPreferences**（schema v2，唯一持久化）；**事件日志仅在内存**（本会话，退出即清空，下次启动以离线结算重新开场）；跨会话**里程碑 = SP 整数计数 `stats`**（01 §9，不为里程碑持久化日志/档案）；历史档案文件化留二期 | 最简数据面 + 可靠 |
| 素材 | 每张 256×256 PNG 为 **4×4 行走图**（4 朝向 × 4 帧，单帧 64×64），切片渲染 | 素材勘误确认 |
| 布局 | 主屏 = 主环三段环形进度条 + 顶部状态图标区（点图标/上缘下拉→状态面板）+ 中央活动区 + 底部上滑操作面板 + 右缘左滑功能清单；面板/清单统一走 **RoundSafe 圆屏组件** | 圆屏信息架构最小化 + 边缘裁切可控 |
| 视觉 | **深色一体基调**（基底纯黑、圆屏与黑边一体、隐藏黑边）；功能页可用**同心圆渐变主题背景**区分（仅深色低饱和、屏缘禁高对比截断）；语义/状态色一律**莫奈低饱和**；UI 主题统一 **Accent**（集中 Token，禁自造色）；菜单/清单/面板条目一律**胶囊**：实心=可点、空心=不可点（类别色可覆写胶囊背景） | 一体观感 + 可点性一眼可辨 + 黑底不刺眼（doc/06 §4/§4.2/§8.3） |
| 手势 | 使用 **上缘下拉（状态面板）/ 下缘上滑（操作面板）/ 右缘左滑（功能清单）**；规避「从左往右」（=系统返回） | 对齐系统下拉 + 避免与系统手势冲突 |
| 启动 | **五阶分阶启动**：黑屏→居中 Logo → 功能菜单就绪→右缘箭头 → 宠物形象活跃 → 一圈状态条 → 底部入口条；**日志+离线结算在末阶后台异步、完成后 apply** | 快捷功能第一时间可用；按优先级逐步完成、不并发拖慢整体（doc/08 §1） |
| 壳/扩展 | **BaseActivity 壳层化**；后续功能以独立 Activity（: BaseActivity）追加、manifest 隔离，首页纯净 | 隔离加载、按需扩展（doc/08 §2） |
| 表现 | 无表情素材 → **状态图标 + 状态面板**做信息通道；情绪用**素材拉伸/形变清单**（蹦跳、压扁…）表达 | 无素材前提下的情绪表达 |
| 功能 | 参照拓麻歌子 10 功能做映射取舍；**v1 = 状态面板 + 投喂/玩耍/抚摸/治疗**（治疗仅 SICK 出现），其余走扩展位；休闲小游戏归入右滑清单 | 轻量第一版 + 可扩展 |

## 3. 玩法循环总览

```
开档选宠(性格特质骰定) → 日常照顾(喂/玩/抚/治, 选食物类型) → 状态驱动即时反馈 → 离线结算(打开即结算) → 长期陪伴
     ↑                                                                                    │
     └──────────── 重复：每天 2~3 次打开，每次 1~2 分钟 ──────────────────────────────────┘
```

- **开档**：任选素材一只；性格特质（好动/粘人/贪吃/好奇/温和/聪慧 6 维）随机生成，形成独一无二的宠物——它走路速度、饿得快慢、粘人程度都由数值决定。
- **日常照顾**：主环随时读三属性；状态图标提示隐藏问题（脏/初级）；宠物 FSM 即时表现（乞食、低头、蹦跳）由属性+trait 驱动。
- **打开即结算**：短离线按速率积分；长离线的每一次衰减都变成**有剧情、有时间戳的离线回放**——饿了等、无聊游荡、被响声吓一跳、梦见好吃的…打开时滚动呈现「在你离开期间发生了…」，回放的**结尾基调**决定迎接开场语气（睡得香→慵懒满足 / 饿趴→委屈乞食）；属性归零不死亡。
- **随机彩蛋**：在线陪伴中的即时小事件（觅食、哈欠、撒娇…），让每次打开都不一样。

## 4. 主屏信息架构（圆形表盘）

```
┌────────────────────────────┐
│  A饱腹 B心情 C健康   (主环)  │   三段 120° 环形进度条（琥珀/青绿/玫红+图标）
│   [状态图标区]              │   异常时才出现：脏💧 / 病✚ / 饿🍽 …
│   ┌──────────────────┐     │
│   │   中央活动区        │     │   宠物切片动画 + 情绪拉伸 + 气泡
│   └──────────────────┘     │
│   ▼上缘下拉=状态面板          │   底部 ▲ = 上滑游戏操作面板
│        ▲上滑提示   ◀左滑提示 │   右缘 ◀ = 左滑展开原生功能清单
└────────────────────────────┘   上缘 ▼ = 下拉状态面板（学系统下拉）
```

| 区域/手势 | 内容 |
|---|---|
| 主环进度条 | 饱腹(碗)/心情(🎈)/健康(十字) 三段三色，数值实时映射；<30 图标呼吸预警 |
| 顶部状态图标区 | 无素材状态的双通道提示（脏/病/困…）；点击 / 上缘下拉 → 状态面板（顶部下拉，学系统） |
| 上缘下拉 | 展开状态面板（与点屏顶图标等效；下面板开着则先收起它） |
| 中央活动区 | 宠物（FSM 状态 × 情绪修饰 × 短脚本动画）+ 气泡 |
| 底部上滑 | **游戏操作面板**：v1 = 投喂(选食物) / 玩耍 / 抚摸 / 治疗 + 首项「状态」（点它=收起下面板、顶部展开状态面板）；状态驱动只显示可用动作 |
| 右缘左滑 | **原生功能清单**：微信/电话/设置/本地动作等插件（见 doc/05），快捷、不依赖宠物状态 |

> 视觉基调 = **纯黑基底 + 深色一体**（圆屏与黑边一体、隐藏黑边）；功能页可用**同心圆渐变深色主题背景**区分页面（低亮低饱和、屏缘禁高对比截断）；鲜艳/语义色统一**莫奈低饱和**（doc/06 §4/§4.2）；菜单/清单/面板条目统一 **胶囊**：实心=可点、空心=不可点（doc/06 §8.3）。
> 详见 [doc/06](./doc/06-UI与交互设计.md)、[doc/07](./doc/07-渲染与动画设计.md)。

## 6. 技术约束清单（AI 开发者须知）

1. **界面框架**：Jetpack Compose for Wear OS。
2. **启动优化**：**五阶分阶启动**——黑屏→居中静态 Logo（壳，原生 View <200ms）→ 功能菜单就绪→右缘箭头 → 宠物形象 → 一圈状态条 → 底部入口条；**日志+离线结算在末阶后台异步、完成后 apply**（doc/08 §1/§3）。
3. **动画渲染**：
   - 禁止重型 Transition 动画 API。
   - 素材 256×256 **4×4 行走图**（单帧 64×64），`Canvas.drawBitmap` 切片绘制；`LaunchedEffect + delay` 驱动 4~6 FPS（doc/07）。
   - 情绪用拉伸/形变（Emotion 清单），无表情素材依赖。
4. **离线与数据**：禁常驻后台 Service；**禁 AlarmManager/定时通知**；「打开即结算」`settle(now)`（doc/01 §8）幂等、归零不致死；长离线的衰减以**事件化回放**（doc/03 §7）写入**内存会话日志开场段**——结算开场 + 在线事件追加成同一条时间线，退出即清空、不落盘，下次启动以新结算重新开场（doc/04 §3）。
5. **存储**：单宠快照 SharedPreferences（单键 JSON，schema v2，含 traits/隐藏属性/冷却/里程碑计数 `stats`）；`stats` 只在动作/事件命中时 +1（doc/01 §9）。
6. **素材管理**：`assets/sprite/` 1339 张按需解码当前宠物 1 张；列表缩略/回收。
7. **手势**：上缘下拉（状态面板）/ 下缘上滑（操作面板）/ 右缘左滑（功能清单）；**规避「从左往右」（系统返回）**。
8. **布局/组件**：归一化坐标圆形活动区，兼容方屏兜底；列表/面板/文本一律走 **RoundSafe/Pill 胶囊组件**（内切安全区 + 边缘渐隐 + 行文截断，doc/06 §8），防圆屏边缘裁切。
9. **domain 层零 Android 依赖**，可单测。
10. **Activity 分层**：主屏 = PetActivity（BaseActivity 壳）；后续功能以独立 FeatureActivity 追加、manifest 隔离，首页不加载非必须功能（doc/08 §1/§2）。
11. **视觉基线**：基底纯黑 `#000000` 深色一体（圆屏与黑边一体，doc/06 §4.1）；功能页可用同心圆渐变主题背景（仅深色低饱和、屏缘禁高对比截断，doc/06 §4.2）；语义/状态色统一莫奈低饱和（doc/06 §4）；UI 主题色统一 `ColorToken.Accent`（默认近白、集中一处可换）；胶囊两级：实心=可点 / 空心=不可点，类别色可覆写胶囊背景（doc/06 §8.3）。

## 7. 工程结构

```
app/src/main/
├── assets/sprite/           # 1339 张 256×256 行走图（宝可梦）
├── java/com/lollipop/tamagotchi/
│   ├── core/                # 值对象、AttributeRegistry、枚举、常量
│   ├── domain/              # settle / FSM / traits / 事件 / 插件注册表
│   ├── data/                # SP 存储、素材仓库、Intent 执行、时钟
│   └── presentation/        # base 壳 + Compose 主屏+面板 + RoundSafe 组件 + Canvas 渲染
└── res/
```
